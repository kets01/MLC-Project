Machine Learning Compiler Lab Report
====================================

This documentation tracks our progress through the Machine Learning Compiler Lab at the University of Jena.
**GitHub Repository:** `https://github.com/kets01/MLC-Project <https://github.com/kets01/MLC-Project>`_

Use the sidebar to navigate: **Weekly Labs** covers weeks 1–7 (the AArch64
assembly → SME/SVE → JIT-codegen → TEIR foundation), and **MLC-Norm
Project** is the capstone built on top of it — LayerNorm/RMSNorm kernels
taken from a scalar reference through SSVE, SME/ZA, JIT generation, and TEIR
integration.
