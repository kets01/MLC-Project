# Sprint 9 — pinned baseline environment.
#
# These are the EXACT versions that produced the external-baseline numbers in
# the report (docs/source/weeks/norm_sprint7_5.rst).  They are pinned rather
# than floated because a "N x faster than library X" margin is a statement
# about a specific version on a specific day, not a property of our kernels:
# on the previous stack (torch 2.4.0 / executorch 0.3.0) the same harness gave
# torch.compile RMSNorm 3.02 GiB/s against 5.90 here, which would have made our
# reported margin 8-13x instead of 4.2-5.8x.  The kernels did not change; the
# baseline did.
#
# REQUIRES PYTHON >= 3.10.  ExecuTorch's XNNPACK partitioner cannot be imported
# on 3.9 (`TypeError: 'staticmethod' object is not callable` — staticmethod
# objects became callable only in 3.10), and XNNPACK is the delegated path that
# is actually deployed, so measuring only the portable reference kernels would
# understate the baseline.
#
# Do NOT install these into `mlc_env`: that environment holds the Sphinx
# toolchain the docs workflow depends on, and ExecuTorch pins its own torch.
#
#   curl -LsSf https://astral.sh/uv/install.sh | sh
#   uv python install 3.12
#   uv venv --python 3.12 /tmp/et312
#   uv pip install --python /tmp/et312/bin/python -r bench/baselines/requirements-baselines.txt

torch==2.13.0
executorch==1.4.1
numpy==2.5.2
